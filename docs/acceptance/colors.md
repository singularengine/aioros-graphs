# Colors

d3-color's color spaces (`Color`, `Rgb`, `Hsl`, `Lab`, `Hcl`, `Cubehelix`) and d3-scale-chromatic's schemes and
interpolators (`ColorSchemes`, `SchemeInterpolator`). Golden fixtures: `Golden/color.json` from
`tools/golden/cases/color.mjs` and `Golden/chromatic.json` from `tools/golden/cases/chromatic.mjs`. Formatted colors
are compared byte for byte; RGB and HSL channels bit for bit. Lab, HCL and cubehelix channels, which go through
`Math.pow`, `Math.atan2`, `Math.sin` and `Math.cos`, are compared within a relative 1e-10, and so are the unrounded
numbers `formatHsl` writes for colors converted through them; their rounded RGB channels are byte for byte except at an
exact .5 tie, where either neighbor is accepted.

| ID | Criterion |
|---|---|
| COLOR-01 | Given each specifier of the `parse` cases (3, 4, 6 and 8 hex digits, `rgb()` and `rgba()` with integers, percentages, exponents, signs and spaces, `hsl()` and `hsla()`, every named color, `transparent`, mixed case and surrounding whitespace), when `Color.TryParse` reads it, then it succeeds exactly where d3's `color(specifier)` returns a color, the color is in d3's space (RGB, or HSL for `hsl()` and `hsla()`), and its channels and opacity equal d3's bit for bit, NaN included. |
| COLOR-02 | Given each specifier of the `rejected` parse cases (5 and 7 hex digits, a missing `#`, decimals in `rgb()` integers, mixed integers and percentages, missing or extra channels, unknown names, the empty string), when `Color.TryParse` reads it, then it returns false, as d3's `color` returns null, and `Rgb.Parse` returns the color whose channels and opacity are all NaN, as `d3.rgb(specifier)` does. |
| COLOR-03 | Given each parsed color of the `parse` cases, when it is formatted with `FormatHex`, `FormatHex8`, `FormatRgb`, `FormatHsl` and `ToString`, then each text equals d3's `formatHex()`, `formatHex8()`, `formatRgb()`, `formatHsl()` and `toString()` byte for byte (channels clamped and rounded as JavaScript's `Math.round`, NaN written as 0, opacity below 1 as `rgba()` and `hsla()`), and the span overloads write the same characters and UTF-8 bytes without allocating. |
| COLOR-04 | Given each parsed color, when it is converted to HSL, Lab, HCL and cubehelix and back to RGB, then each space's channels equal d3's `hsl(c)`, `lab(c)`, `hcl(c)` and `cubehelix(c)` (HSL bit for bit, the others within 1e-10), achromatic colors keep d3's NaN hue and chroma, and each converted color formats as d3's `formatRgb()` byte for byte. |
| COLOR-05 | Given each parsed color in each space, when `Brighter` and `Darker` run with no factor, 1, 2.5 and -1, then the results equal d3's `brighter(k)` and `darker(k)` (multiplied by 0.7 to the power k in RGB, HSL and cubehelix, shifted by 18 k in Lab and HCL lightness), formatted byte for byte. |
| COLOR-06 | Given each parsed color in each space, when `IsDisplayable` and `Clamp` run, then they equal d3's `displayable()` and `clamp()` (RGB channels rounded into [0, 255], HSL hue into [0, 360), saturation and lightness into [0, 1], opacity into [0, 1] and NaN to 1). |
| COLOR-07 | Given the channels of the `constructed` cases (out of range, negative, NaN hue and saturation, zero opacity), when `Rgb`, `Hsl`, `Lab`, `Hcl` (also built as `Lch`), `Cubehelix` and `Lab.Gray` colors are built from them, then their conversions and formats equal d3's `rgb(r, g, b, a)`, `hsl(h, s, l, a)`, `lab(l, a, b)`, `hcl(h, c, l)`, `lch(l, c, h)`, `cubehelix(h, s, l)` and `gray(l)`. |
| CHROMA-01 | Given each categorical scheme (category10, Accent, Dark2, Observable10, Paired, Pastel1, Pastel2, Set1, Set2, Set3, Tableau10), when `ColorSchemes` returns it, then its colors equal d3-scale-chromatic's `scheme*` array, in order. |
| CHROMA-02 | Given each ColorBrewer diverging and sequential scheme (BrBG, PRGn, PiYG, PuOr, RdBu, RdGy, RdYlBu, RdYlGn, Spectral, Blues, Greens, Greys, Oranges, Purples, Reds, BuGn, BuPu, GnBu, OrRd, PuBuGn, PuBu, PuRd, RdPu, YlGnBu, YlGn, YlOrBr, YlOrRd) and each size k from 0 to 12, when `ColorSchemes.Scheme(name, k)` runs, then it returns d3's `scheme*[k]`, empty where d3 has no scheme of that size. |
| CHROMA-03 | Given each interpolator of d3-scale-chromatic (the ColorBrewer ones, viridis, magma, inferno, plasma, cividis, turbo, warm, cool, rainbow, sinebow, cubehelixDefault) and each t of the `interpolators` cases (0 to 1 by 0.1, ends, values between table entries, below 0 and above 1), when `SchemeInterpolator.Format` runs, then the text equals d3's `interpolate*(t)` byte for byte, a hex color for the four 256-entry ramps and `rgb()` for the others, and `Interpolate` returns the color that formats to it. |
