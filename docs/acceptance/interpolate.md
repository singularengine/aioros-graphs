# Interpolation

d3-interpolate's interpolators, as structs implementing `IInterpolator<T>` (`Interpolation` namespace), and d3's
generic `interpolate` over the typed union `InterpolationValue` (`ValueInterpolator`). Golden
fixture: `Golden/interpolate.json`, from `tools/golden/cases/interpolate.mjs`. Numbers are compared bit for bit except
where noted; colors are compared as d3 formats them (`formatRgb`), byte for byte.

| ID | Criterion |
|---|---|
| INTERP-01 | Given each pair of numbers of the `number` cases (equal, reversed, infinite and NaN ends) and each t (0, 1, between, below 0, above 1, NaN), when `NumberInterpolator` and `RoundInterpolator` interpolate, then the values equal d3's `interpolateNumber(a, b)(t)` and `interpolateRound(a, b)(t)` bit for bit. |
| INTERP-02 | Given each pair of angles of the `hue` cases (across 0 and 360, more than half a turn apart, NaN), when `HueInterpolator` interpolates at each t, then the value equals d3's `interpolateHue(a, b)(t)`. |
| INTERP-03 | Given each list of numbers of the `basis` cases (one, two and many values) and each t (including below 0 and above 1), when `BasisInterpolator` and `BasisInterpolator.Closed` interpolate, then the values equal d3's `interpolateBasis(values)(t)` and `interpolateBasisClosed(values)(t)` bit for bit. |
| INTERP-04 | Given each list of the `discrete` cases and each t, when `DiscreteInterpolator` interpolates, then it returns d3's `interpolateDiscrete(values)(t)`, the first value below 0 and the last from 1. |
| INTERP-05 | Given each pair of number arrays of the `numberArray` cases (equal lengths, a shorter start, a shorter end, empty), when `NumberArrayInterpolator` interpolates at each t, then the values equal d3's `interpolateNumberArray(a, b)(t)`: the end's length, the extra values taken from the end, bit for bit. |
| INTERP-06 | Given each pair of colors of the `colors` cases (named, hex with opacity, `transparent`, achromatic grays and white, `hsl()` colors) and each t (0, 1, between, below 0, above 1), when `RgbInterpolator` (gamma 1 and 2.2), `HslInterpolator` (short and long hue), `LabInterpolator`, `HclInterpolator` (short and long) and `CubehelixInterpolator` (short and long, gamma 1 and 3) interpolate, then each color formats as d3's `interpolateRgb`, `interpolateRgb.gamma(2.2)`, `interpolateHsl`, `interpolateHslLong`, `interpolateLab`, `interpolateHcl`, `interpolateHclLong`, `interpolateCubehelix`, `interpolateCubehelixLong` and their `.gamma(3)` byte for byte, missing hues and saturations taken from the other end as d3 does. |
| INTERP-07 | Given each list of colors of the `rgbBasis` cases (one, two and many colors, an invalid color), when `RgbBasisInterpolator` and `RgbBasisInterpolator.Closed` interpolate at each t, then each color formats as d3's `interpolateRgbBasis(colors)(t)` and `interpolateRgbBasisClosed(colors)(t)` byte for byte. |
| INTERP-08 | Given each list of the `piecewise` cases (numbers and colors), when `PiecewiseInterpolator` built from number and RGB interpolators interpolates at each t, then it returns d3's `piecewise(interpolateNumber, values)(t)` and formats as `piecewise(interpolateRgb, colors)(t)`. |
| INTERP-09 | Given an interpolator and each n of the `quantize` cases (1, 2, 5), when `Interpolators.Quantize` samples it, then the samples equal d3's `quantize(interpolator, n)`, NaN positions included for n = 1. |
| INTERP-10 | Given each pair of views of the `zoom` cases (panning, zooming in place, both, with rho 1, √2 and 4), when `ZoomInterpolator` interpolates at each t, then the center and width and the duration equal d3's `interpolateZoom.rho(rho)(p0, p1)(t)` and `.duration` within a relative 1e-12 (`Math.exp`, `Math.log` and `Math.sqrt` differ between V8 and .NET in the last bits). |
| INTERP-11 | Given an RGB, HSL, Lab, HCL, cubehelix or scheme interpolator, when 1,000 colors are interpolated and written with the span formatters, then nothing is allocated. |
| INTERP-12 | Given each pair of strings of the `string` cases (numbers with signs, fractions and exponents, matching and differing numbers, more numbers on either side, no numbers, empty strings, malformed exponents), when `StringInterpolator` interpolates at each t, then the text equals d3's `interpolateString(a, b)(t)` byte for byte, numbers written as JavaScript's `String(x)`, and `TryInterpolate` writes the same text into a span without allocating. |
| INTERP-13 | Given each pair of times of the `date` cases, when `DateInterpolator` interpolates at each t, then the time value equals d3's `+interpolateDate(a, b)(t)` bit for bit, clipped as `Date.setTime` clips it (NaN beyond ±8.64e15 ms or at a NaN t). |
| INTERP-14 | Given each pair of `InterpolationValue`s of the `value` cases whose end is undefined, null, a boolean, a number, a string (a color or not), a color, a date or a number array, when `Interpolators.Value(a, b)` interpolates at each t, then the value and its kind equal d3's `interpolate(a, b)(t)`: a constant end, numbers through JavaScript's `ToNumber` of the start, colors in RGB written as `rgb()` text, strings through `interpolateString` of the start's text, dates as time values, number arrays element by element. |
| INTERP-15 | Given each pair of the `value` cases whose end is an array or an object, when `Interpolators.Value(a, b)` interpolates at each t, then the array or object equals d3's `interpolate(a, b)(t)`: elements and members present in both interpolated recursively, the others taken from the end, an object's members in JavaScript's property order (integer keys ascending, then the end's own members, then the shared ones); and where d3 throws a `RangeError` (a start with no length against an array), `Interpolators.Value` throws an `ArgumentException`. |
