# Scales

d3-scale's scales: linear, band, point and UTC (`LinearScale`, `BandScale`, `PointScale`, `UtcScale`), log, pow and
sqrt, symlog and radial (`LogScale`, `PowScale`, `SymlogScale`, `RadialScale`), ordinal, quantize, quantile and
threshold (`OrdinalScale`, `QuantizeScale`, `QuantileScale`, `ThresholdScale`), sequential and diverging
(`SequentialScale`, `SequentialQuantileScale`, `DivergingScale`), and local time (`TimeScale`). Golden fixtures: `Golden/scale.json`,
`Golden/scale-continuous.json`, `Golden/scale-sequential.json`, `Golden/scale-discrete.json`, `Golden/scale-color.json` and `Golden/localtime.json`, from the modules of the
same names in `tools/golden/cases`. Values are compared bit for bit.

| ID | Criterion |
|---|---|
| SCALE-01 | Given each configuration of the `linear` cases (ascending, descending and empty domains and ranges, two and more stops, domains longer than ranges), when `LinearScale.Map` maps each input (including ±Infinity), then it returns exactly d3's `scale(x)`, and `Map` over a span writes the same values. |
| SCALE-02 | Given a linear scale, when it maps NaN, then it returns NaN, as d3 returns its undefined unknown value. |
| SCALE-03 | Given each clamped configuration of the `linear` cases, when inputs outside the domain are mapped and inverted, then the outputs stay within the range and the inverted values within the domain, exactly as d3's `clamp(true)`. |
| SCALE-04 | Given each `rangeRound` configuration of the `linear` cases, when inputs are mapped, then the outputs are d3's rounded values (`interpolateRound`). |
| SCALE-05 | Given each configuration of the `linear` cases, when `LinearScale.Invert` inverts each input as a range value, then it returns exactly d3's `scale.invert(y)`. |
| SCALE-06 | Given each configuration of the `linear` cases, when `LinearScale.Ticks` runs with counts 1, 2, 5, 10 and 20, then it returns exactly d3's `scale.ticks(count)`, and the span overload writes the same values. |
| SCALE-07 | Given each configuration of the `linear` cases with a `nice` count, when `LinearScale.Nice` runs, then the new scale's domain equals d3's niced domain (extending only the first and last stops, at most 10 iterations), and the original scale is unchanged. |
| SCALE-08 | Given each configuration of the `band` cases (inner, outer and shared padding, inner padding above 1, align outside [0, 1], reversed and rounded ranges, one and zero bands), when `BandScale` is built, then `Step`, `Bandwidth` and the start of each band equal d3's `scaleBand`. |
| SCALE-09 | Given a band or point scale, when an index below 0 or not below the count is mapped, then NaN is returned, as d3 returns undefined for an unknown key. |
| SCALE-10 | Given each configuration of the `point` cases, when `PointScale` is built, then `Step`, `Bandwidth` (always 0) and each point equal d3's `scalePoint`. |
| SCALE-11 | Given a linear scale, when it is created with fewer than two domain or range values, then an `ArgumentException` is thrown; and when a band scale is created with a negative count, an `ArgumentOutOfRangeException` is thrown. |
| SCALE-12 | Given each domain, count and specifier of the `linearFormat` cases (the default, percentages with a sign, currency, SI prefixes, exponents, significant digits, a descending domain), when `LinearScale.TickFormat` formats each tick, then each label equals d3's `scale.tickFormat(count, specifier)`, precision derived from the tick step as d3 does. |
| SCALE-13 | Given each configuration of the `utc` cases (hours to centuries, reversed, clamped, rounded and piecewise), when `UtcScale.Map` maps instants inside, at and beyond the domain and `Invert` inverts range values, then the results equal d3's `scaleUtc`: inputs and inverted values are JavaScript time values, truncated to whole milliseconds, and infinite or NaN instants map to NaN. |
| SCALE-14 | Given each configuration of the `utc` cases, when `UtcScale.Ticks` runs with counts 3, 5, 10 and 20 and with explicit intervals (day, hour, month, every 15 minutes, year, week), then the ticks equal d3's `scale.ticks(count)` and `scale.ticks(interval)`; `UtcScale.Ticks(count, destination)` writes the same ticks as the array overload into a span of `MaxTickCount(count)` values. |
| SCALE-15 | Given each configuration of the `utc` cases, when `UtcScale.Nice` runs with counts 10 and 5, then the domain equals d3's `scale.nice(count).domain()`. |
| SCALE-16 | Given each configuration and count of the `utc` cases, when `UtcScale.TickFormat` labels each tick (the count is ignored, as d3 ignores it) with the default format and with `%Y-%m-%d %H:%M`, then the labels equal d3's `scale.tickFormat(count)` (the multi-scale format: `.%L`, `:%S`, `%I:%M`, `%I %p`, `%a %d`, `%b %d`, `%B`, `%Y`) and `scale.tickFormat(count, specifier)`. |
| SCALE-17 | Given each configuration of the `log` cases (bases 10, 2, e, 3 and 2.5, ascending, descending and negative domains, piecewise, clamped and rounded), when `LogScale.Map` maps each input and `Invert` inverts each as a range value, then the results equal d3's `scaleLog()` bit for bit, NaN where d3 returns undefined. |
| SCALE-18 | Given each configuration of the `log` cases, when `LogScale.Ticks` runs with counts 10, 1, 2, 5 and 20, then it returns d3's `scale.ticks(count)`: each power's multiples within the domain for integer bases, linear ticks when too few, exponent ticks otherwise, reversed for descending domains; the span overload writes the same values. |
| SCALE-19 | Given each configuration and count of the `log` cases, when `LogScale.TickFormat(count, specifier)` labels each tick (the default `s` for base 10 and `,` otherwise, trimmed for integer bases; explicit specifiers; an infinite count), then each label equals d3's `scale.tickFormat(count, specifier)`, empty for the ticks d3 hides. |
| SCALE-20 | Given each `log` case with nice, when `LogScale.Nice` runs, then the domain equals d3's `scale.nice().domain()`: the first and last stops rounded out to powers of the base. |
| SCALE-21 | Given each configuration of the `pow` and `sqrt` cases (exponents 2, 0.5, 3, 0.25, 1, -1 and 1.7, negative inputs, piecewise, clamped, rounded and niced), when `PowScale` maps, inverts, ticks, nices and formats ticks, then every result equals d3's `scalePow().exponent(e)` and `scaleSqrt()`. |
| SCALE-22 | Given each configuration of the `symlog` cases (constants 1, 0.5 and 10, clamped, rounded and niced), when `SymlogScale` maps, inverts, ticks, nices and formats ticks, then every result equals d3's `scaleSymlog().constant(c)`, with `log1p` and `expm1` computed as V8 computes them. |
| SCALE-23 | Given each configuration of the `radial` cases (ranges from zero and from an inner radius, negative ranges, clamped, rounded and niced), when `RadialScale` maps, inverts, ticks, nices and formats ticks, then every result equals d3's `scaleRadial()`. |
| SCALE-24 | Given a log, pow, symlog or radial scale, when it is created with fewer than two domain or range stops, then an `ArgumentException` is thrown, and mapping NaN returns NaN. |
| SCALE-25 | Given each configuration of the `sequential` cases (linear, log, pow, sqrt and symlog, ascending, descending and empty domains, clamped), when `SequentialScale.Map` maps each input through d3's default identity interpolator, the number interpolator of `range` and the rounded one of `rangeRound`, then the outputs equal d3's `scaleSequential*()` bit for bit: 0.5 for an empty domain, the unknown value for NaN, and `Range` returns d3's `scale.range()`. |
| SCALE-26 | Given each configuration of the `sequential` cases, when `SequentialScale.Ticks`, `TickFormat` and `Nice` run, then the ticks, labels and niced domain equal d3's: linear ticks for the linear, pow, sqrt and symlog kinds, log ticks, labels and nice for the log kind. |
| SCALE-27 | Given each configuration of the `diverging` cases (linear, log, pow, sqrt and symlog, ascending, descending and degenerate halves, clamped), when `DivergingScale.Map` maps each input through the identity interpolator and through d3's piecewise number interpolators of `range` and `rangeRound`, then the outputs equal d3's `scaleDiverging*()` bit for bit, and `Range` returns d3's `scale.range()`. |
| SCALE-28 | Given each configuration of the `diverging` cases, when `DivergingScale.Ticks`, `TickFormat` and `Nice` run, then the ticks, labels and niced domain equal d3's, from the first and last of the three stops. |
| SCALE-29 | Given each domain of the `quantile` sequential cases (unsorted, with NaN, a single value, 100 values), when `SequentialQuantileScale` is built, then its sorted domain, each input's output, `Range` and `Quantiles(n)` for n 1, 4 and 10 equal d3's `scaleSequentialQuantile()`. |
| SCALE-30 | Given a sequential or diverging scale, when its domain does not have exactly two (sequential) or three (diverging) stops, then an `ArgumentException` is thrown, and when NaN is mapped, the scale's unknown value is returned without calling the interpolator. |
| SCALE-31 | Given each configuration of the `ordinal` cases (repeated domain keys, ranges shorter and longer than the domain, an empty domain, an explicit unknown value), when `OrdinalScale` maps each probe in order, extending an implicit domain with `Extend` for each new key, then the values equal d3's `scaleOrdinal()` (the range cycled by key index) and the final domain equals d3's grown domain; with an explicit unknown value, new keys map to it and the domain does not grow. |
| SCALE-32 | Given an ordinal scale without an unknown value, when `Map` is given a key outside its domain, then a `KeyNotFoundException` is thrown and `TryMap` returns false; and when the range is empty, every key maps to the unknown value. |
| SCALE-33 | Given each configuration of the `quantize` cases (ascending, descending and empty domains, one to nine range values, niced), when `QuantizeScale` is built, then its thresholds, each input's range value, `InvertExtent` of each range value (NaN for a value outside the range), its ticks, tick labels and niced domain equal d3's `scaleQuantize()`. |
| SCALE-34 | Given each configuration of the `quantile` cases (unsorted samples with NaN and signed zeros, one value, none, 200 values, an empty range), when `QuantileScale` is built, then its sorted domain, `Quantiles`, each input's range value and `InvertExtent` of each range value equal d3's `scaleQuantile()`, the unknown value standing for d3's undefined. |
| SCALE-35 | Given each configuration of the `threshold` cases (thresholds fewer, as many as and more than the range allows, none), when `ThresholdScale` maps each input and inverts each range value, then the results equal d3's `scaleThreshold()`, NaN standing for d3's undefined bounds. |
| SCALE-36 | Given a quantize scale, when it is created with an empty range, then an `ArgumentException` is thrown; and given a quantize, quantile or threshold scale, when NaN is mapped, then its unknown value is returned. |
| SCALE-37 | Given each scheme (viridis, plasma, turbo, Blues, YlOrRd; RdBu, RdYlGn, PuOr, Spectral), kind (linear, sqrt, log, symlog) and domain (ascending, descending, three stops) of the `scale-color` cases, when a `SequentialScale` or `DivergingScale` over d3-scale-chromatic's interpolator positions each input and the interpolator formats the color, then the text equals d3's `scaleSequential(domain, interpolator)(x)` (hex for the ramps, `rgb()` for the others), the mapped `Rgb` is the interpolator's value at that position, and where d3 returns undefined the position is NaN: a NaN input, which maps to the scale's unknown value, or a value outside a log domain fed to a ramp scheme. |
| SCALE-40 | Given each zone and domain of the local `scale` cases, when `TimeScale.Create(domain, [0, 960], zone)` maps the domain's ends, its middle and a day before it, and inverts the results, then the values equal d3's `scaleTime()` (a linear map of time values, as the UTC scale). |
| SCALE-41 | Given each zone and domain of the local `scale` cases, when `TimeScale.Ticks` runs with counts 3 and 10 and with explicit local intervals (day, hour, month, every 15 minutes, week), then the ticks equal d3's `scaleTime().ticks(count)` and `ticks(interval)`, and the span overload writes the same ticks into `MaxTickCount(count)` values. |
| SCALE-42 | Given each zone and domain of the local `scale` cases, when `TimeScale.Nice` runs with counts 10 and 5 and with `TimeInterval.Day`, then the domain equals d3's `scale.nice(count).domain()` and `scale.nice(timeDay).domain()`. |
| SCALE-43 | Given each zone and domain of the local `scale` cases, when `TimeScale.TickFormat` labels the ticks with the default format and with `%Y-%m-%d %H:%M %Z`, then the labels equal d3's `scaleTime().tickFormat(count)` and `tickFormat(count, specifier)` in that zone. |
