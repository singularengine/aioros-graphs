# Shapes

d3-shape's generators: lines and areas with their curves, arcs, pies and stacks (`Line`, `Area`, `Curve`, `Arc`,
`Pie`, `Stacks`), symbols, links and radial lines and areas (`Symbol`, `Link`, `LineRadial`, `AreaRadial`, `Radial`).
Golden fixtures: `Golden/shape.json` from `tools/golden/cases/shape.mjs` and `Golden/shape-extra.json` from
`tools/golden/cases/shape-extra.mjs`. Path data is compared byte for byte with d3's output, at d3-shape's default 3
digits and unrounded; where sines and cosines enter (arcs, star symbols, radial shapes, radial links) the unrounded
numbers are compared within a relative 1e-12.

| ID | Criterion |
|---|---|
| SHAPE-01 | Given each series of the `lines` cases (empty, one, two and many points, coincident and vertical points, gaps marked undefined, descending x, fractions) and each curve (linear, monotoneX, monotoneY, natural, step, stepBefore, stepAfter, basis, cardinal with tension 0 and 0.5, catmullRom with alpha 0, 0.5 and 1), when `Line.Write` writes it through an `SvgPathWriter`, then the path data equals d3's `line()` with that curve and digits; an empty or fully undefined series writes nothing, as d3 returns null. |
| SHAPE-02 | Given each series and curve of the `areas` cases, with a per-point baseline, when `Area.Write` writes it, then the path data equals d3's `area()`: the topline forward, the baseline backward, each defined segment closed. |
| SHAPE-03 | Given an area with a single baseline value and a separate `x1` for the topline, when `Area.Write` writes it for each curve, then the path data equals d3's `area().x0().x1().y0(constant)`. |
| SHAPE-04 | Given a line or an area, when the coordinate spans have different lengths, or the defined span is neither empty nor of the data's length, then an `ArgumentException` is thrown. |
| SHAPE-05 | Given each arc of the `arcs` cases (sectors, annuli, full circles and rings, swapped radii, a point, reversed and over-full angles, pad angles with and without pad radius, collapsing pads, corner radii that fit, merge and are clamped), when `Arc.Write` writes it, then the path data equals d3's `arc()` byte for byte at 3 digits, and unrounded within a relative 1e-12 per number (V8's fdlibm and .NET's sine, cosine and arctangent may differ in the last bits), and `Arc.Centroid` equals d3's `arc.centroid` the same way. |
| SHAPE-06 | Given each value list and setting of the `pies` cases (descending default sort, no sort, ascending sort, custom start and end angles beyond a full turn, pad angles, negative, zero and NaN values, empty input), when `Pie.Compute` runs, then each slice's index, value, start angle, end angle and pad angle equal d3's `pie()`, in input order, and ties keep their input order. |
| SHAPE-07 | Given a pie, when the slice span is shorter than the values, then an `ArgumentException` is thrown. |
| SHAPE-08 | Given each matrix of the `stacks` cases (positive, mixed signs, NaN gaps, a single value, no rows) with each order (none, reverse, ascending, descending, insideOut, appearance) and offset (none, expand, diverging, silhouette, wiggle), when `Stacks.Compute` runs, then the stacking order and every lower and upper value equal d3's `stack()`. |
| SHAPE-09 | Given a stack, when the values are not a whole number of rows of the series count, or the point or order spans are too short, then an `ArgumentException` is thrown. |
| SHAPE-10 | Given each series of the `lines` cases of `shape-extra` (empty, one to many points, coincident points, gaps) and each curve linearClosed, basisClosed, basisOpen, bundle (β 0.85, 0.5, 1 and 0), cardinalClosed and cardinalOpen (tension 0 and 0.5), catmullRomClosed and catmullRomOpen (α 0.5, 0 and 1), bumpX and bumpY, when `Line.Write` writes it at 3 digits and unrounded, then the path data equals d3's `line().curve(curve)`, closed curves closing each segment and open curves dropping the first and last points. |
| SHAPE-11 | Given each series of the `areas` cases of `shape-extra` with a per-point baseline and each of those curves but bundle, when `Area.Write` writes it, then the path data equals d3's `area().curve(curve)`: the closed curves closing the topline and the baseline separately, the open and bump curves joining them as d3 does. |
| SHAPE-12 | Given an area with at least one defined point and the bundle curve, when `Area.Write` runs, then an `InvalidOperationException` is thrown, as d3's bundle curve has no `areaStart` and d3 throws; and given an area with no defined point, nothing is written, as in d3. |
| SHAPE-13 | Given each symbol type of the `symbols` cases (circle, cross, diamond, square, star, triangle, wye, plus, times, triangle2, asterisk, square2, diamond2) and each size (the default 64, 0, 1, 2.5, 30.25, 100, 1000, -1), when `Symbol.Write` writes it at the origin, then the path data equals d3's `symbol(type, size)()`, at 3 digits and unrounded. |
| SHAPE-14 | Given each symbol type and three centers of the `translatedSymbols` cases, when `Symbol.Write` writes the three symbols into one path at those centers, then the path data equals d3's symbols drawn into one path through a context that translates every coordinate by the center. |
| SHAPE-15 | Given `Symbol.Fill` and `Symbol.Stroke`, when they are read, then they list the types of d3's `symbolsFill` and `symbolsStroke` in d3's order. |
| SHAPE-16 | Given each source and target of the `links` cases and each of linkHorizontal, linkVertical and `link(curve)` with linear, step, monotoneX, natural, basis, bumpX and catmullRom, when `Link.Write`, `Link.Horizontal` or `Link.Vertical` writes it, then the path data equals d3's, at 3 digits and unrounded, and several links written into one path equal d3's links drawn on one context. |
| SHAPE-17 | Given each source and target of the `radialLinks` cases, when `Link.Radial` writes it, then the path data equals d3's `linkRadial()`, exactly at 3 digits and within a relative 1e-12 unrounded. |
| SHAPE-18 | Given each series of the `radialLines` cases (angles and radii, gaps) and each curve (linear, monotoneX, natural, basis, cardinal, catmullRom, step, the closed and open curves, bundle and bumpX), when `LineRadial.Write` writes it, then the path data equals d3's `lineRadial().curve(curve)`, exactly at 3 digits and within a relative 1e-12 unrounded. |
| SHAPE-19 | Given each series and curve of the `radialAreas` cases (a constant inner radius, a per-point inner radius, separate start and end angles), when `AreaRadial.Write` writes it, then the path data equals d3's `areaRadial()` with `startAngle`, `endAngle`, `innerRadius` and `outerRadius`, exactly at 3 digits and within a relative 1e-12 unrounded. |
| SHAPE-20 | Given each angle and radius of the `pointRadial` cases, when `Radial.Point` runs, then it returns d3's `pointRadial(angle, radius)` within a relative 1e-12. |
| SHAPE-21 | Given a radial line or area whose angle, radius or defined spans have different lengths, or a symbol type that is not defined, when it is written, then an `ArgumentException` (an `ArgumentOutOfRangeException` for the type) is thrown and nothing is written. |
