# Formats

d3-format's number formats (`FormatSpecifier`, `NumberFormat`, `FormatPrecision`, `NumberLocale`), d3-scale's linear
tick format (`TickFormat`) and d3-time-format's UTC and local formats (`UtcTimeFormat`, `TimeFormat`, `TimeLocale`), in
d3's default en-US locale and in every locale d3 ships (`d3-format/locale`, `d3-time-format/locale`). Golden
fixtures: `Golden/format.json` from `tools/golden/cases/format.mjs`, `Golden/time.json` from
`tools/golden/cases/time.mjs`, `Golden/localtime.json` from `tools/golden/cases/localtime.mjs` and
`Golden/locale.json` from `tools/golden/cases/locale.mjs`. Parsing (`UtcTimeParse`, `TimeParse`) is checked against
`Golden/parse.json` from `tools/golden/cases/parse.mjs`. Not ported: `isoParse`, which is the host's `Date` parser.

| ID | Criterion |
|---|---|
| FORMAT-01 | Given each specifier of the `formats` cases, when `FormatSpecifier.Parse` reads it, then `ToString` returns d3's normalized `formatSpecifier(specifier).toString()`, with its fill, alignment, sign, symbol, zero flag, width, comma, precision, trim and type. |
| FORMAT-02 | Given each specifier of the `formats` cases (every type `e f g r s % p d x X o b c n` and none, trimming, grouping with and without zero fill, every alignment, signs, currency and base prefixes, widths) and each value of the `values` case (zeros, ties, negatives, tiny and huge numbers, NaN and infinities), when `NumberFormat.Create(specifier).Format(value)` runs, then the text equals d3's `format(specifier)(value)`, with the minus sign U+2212. |
| FORMAT-03 | Given each specifier of the `rejected` cases, when `NumberFormat.Create` or `FormatSpecifier.Parse` reads it, then a `FormatException` is thrown, as d3 throws "invalid format". |
| FORMAT-04 | Given each specifier and reference value of the `prefix` cases, when `NumberFormat.CreatePrefix(specifier, reference).Format(value)` runs for each value, then the text equals d3's `formatPrefix(specifier, reference)(value)`: one SI prefix chosen from the reference, `µ` for micro. |
| FORMAT-05 | Given each step and value of the `precision` cases, when `FormatPrecision.Fixed`, `Prefix` and `Round` run, then they return d3's `precisionFixed`, `precisionPrefix` and `precisionRound`. |
| FORMAT-06 | Given each domain, count and specifier of the `ticks` cases (including none, which defaults to `,f`), when `TickFormat.Create(start, stop, count, specifier)` formats the domain's ticks, then each label equals d3-scale's `scaleLinear().domain([start, stop]).tickFormat(count, specifier)` output, with the precision d3 derives from the tick step. |
| FORMAT-07 | Given each specifier of the time `formats` cases (every directive, the week numbers `%U`, `%W` and `%V`, the ISO years `%g` and `%G`, the locale's `%c`, `%x` and `%X`, the `-`, `_` and `0` pad modifiers, literal text, unknown directives and a trailing `%`) and each date of the `dates` case (before 1970, years below 100 and negative, fractional milliseconds, the first and last days of ISO years), when `UtcTimeFormat.Create(specifier).Format(milliseconds)` runs, then the text equals d3's `utcFormat(specifier)(date)`; `TryFormat` writes the same text into a span of `MaxLength` characters, and returns false with nothing written when the span is too short for the text. |
| FORMAT-08 | Given each date of the `multiScale` cases, when `UtcTimeFormat.MultiScale` formats it, then the text equals the default tick format of d3's `scaleUtc()`: `.%L`, `:%S`, `%I:%M`, `%I %p`, `%a %d`, `%b %d`, `%B` or `%Y`, the first whose boundary the date is not on; `UtcTimeFormat.TryMultiScale` writes the same label into a span. |
| FORMAT-09 | Given each zone, specifier and date of the local `formats` cases (every directive including the week numbers, the ISO years and `%c`, `%x` and `%X`, `%Z` with half-hour and negative offsets, an invalid date), when `TimeFormat.Create(specifier, zone).Format` runs, then the text equals d3's `timeFormat(specifier)` run in that zone, and `TryFormat` writes the same text into a span. |
| FORMAT-10 | Given each zone and date of the local `multiScale` cases, when `TimeFormat.MultiScale(date, zone)` formats it, then the text equals the default tick format of d3's `scaleTime()` in that zone, the boundaries being the zone's local seconds, minutes, hours, days, Sundays, months and years, and `TimeFormat.TryMultiScale` writes the same label into a span. |
| FORMAT-11 | Given each locale definition of d3-format (`numberLocales`, all 59) and of d3-time-format (`timeLocales`, all 34), when `NumberLocale.Get(name)` and `TimeLocale.Get(name)` return them, then their decimal mark, thousands separator, grouping, currency, numerals, percent sign, minus sign and NaN text, and their `%c`, `%x` and `%X` formats, periods, weekday and month names equal the definition (with d3's defaults where it gives none); `TryGet` returns false and `Get` throws `ArgumentException` for an unknown name. |
| FORMAT-12 | Given each number locale and specifier of the `numberFormats` cases and each value of the `values` case, when `NumberFormat.Create(specifier, locale).Format(value)` runs, then the text equals d3's `formatLocale(definition).format(specifier)(value)` (the locale's decimal mark, grouping, currency, percent sign, minus sign and numerals), and for the `prefixFormats` cases `NumberFormat.CreatePrefix(specifier, reference, locale)` equals `formatPrefix`. |
| FORMAT-13 | Given each number locale, domain, count and specifier of the `tickFormats` cases, when `TickFormat.Create(start, stop, count, specifier, locale)` labels the ticks, then the labels equal d3's `scaleLinear().tickFormat(count, specifier)` with that locale as d3's default (`formatDefaultLocale`). |
| FORMAT-14 | Given each time locale and specifier of the `timeFormats` cases and each date of the `dates` case, when `UtcTimeFormat.Create(specifier, locale).Format(date)` runs, then the text equals d3's `timeFormatLocale(definition).utcFormat(specifier)(date)`; and given each zone, locale and specifier of the local `localeFormats` cases, `TimeFormat.Create(specifier, zone, locale).Format` equals `timeFormatLocale(definition).format(specifier)` run in that zone. |
| FORMAT-15 | Given each time locale and UTC domain of the `multiScale` locale cases, when `UtcTimeFormat.MultiScale(tick, locale)` and `UtcScale.TickFormat("%c", locale)` label the ticks, then the labels equal d3's `scaleUtc().tickFormat()` and `tickFormat(10, "%c")` with that locale as d3's default (`timeFormatDefaultLocale`). |
| FORMAT-16 | Given each specifier of the `utc` parse cases (every directive d3 parses: `%a %A %b %B %c %d %e %f %g %G %H %I %j %L %m %M %p %q %Q %s %S %u %U %V %w %W %x %X %y %Y %Z %%`, with the `-`, `_` and `0` modifiers, literals, an unknown directive and a trailing `%`) and each input (the formatted dates, lowered, raised, extended, prefixed and truncated, and odd texts), when `UtcTimeParse.Create(specifier).TryParse(text)` runs, then it succeeds exactly where d3's `utcParse(specifier)(text)` returns a date, with the same time value bit for bit (NaN where d3 returns an invalid date: out-of-range timestamps), and fails where d3 returns null (an input left over or too short, a name, number, zone or literal that does not match, a week number `%V` outside 1 to 53). |
| FORMAT-17 | Given each of the 34 time locales and the specifiers `%c`, `%x`, `%X`, `%A %-d %B %Y`, `%a %b %d %I %p`, `%B` and `%b` of the `locales` parse cases, and dates formatted in that locale (lowered, raised, extended, prefixed and truncated), when `UtcTimeParse.Create(specifier, locale).TryParse` runs, then the result equals d3's `timeFormatLocale(definition).utcParse(specifier)`: names matched case-insensitively in the locale's order, the first name that matches winning. |
| FORMAT-18 | Given each zone, specifier and input of the `local` parse cases (wall times around the zone's daylight-saving transitions, in their gaps and repetitions, years 0 to 99, `%Z` offsets, week-based and day-of-year dates, timestamps), when `TimeParse.Create(specifier, zone).TryParse` runs, then the time value equals d3's `timeParse(specifier)` run in that zone, a wall time resolved as ECMAScript's `Date` resolves it. |
| FORMAT-19 | Given a specifier, when `UtcTimeParse.Parse` and `TimeParse.Parse` read a text d3 rejects, then they return null; and given a null specifier, text or locale, an `ArgumentNullException` is thrown. |
