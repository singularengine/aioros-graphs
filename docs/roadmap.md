# Roadmap

What Aioros.Graphs covers today and what comes next. It is in public preview, so its APIs can still change.

## What exists today

- [x] Arrays, scales, shapes, curves, paths, and number and time formats, tested against d3 7.9.0
- [x] Colors, interpolators and the d3 color schemes
- [x] Hierarchies, chords, Sankey diagrams and forces
- [x] Axes as data and as markup
- [x] SVG output for the web and native geometry for the desktop
- [x] Preview packages on NuGet

## What comes next

- A faster shortest round-trip number formatter, which would speed up every chart family.
- Faster ribbon writing when ribbons are not rounded, the one case where d3 is faster.
- A demo site hosted publicly.
- Whatever the chart libraries built on it need.
