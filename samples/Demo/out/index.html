Aioros.Graphs demo

19 d3 gallery charts drawn twice from the same data: by Aioros.Graphs (C#, a port of d3) and by d3 itself (d3 7.9.0; the sankey with d3-sankey 0.12.3). Scales, ticks, tick labels and path data come from each library; the axes, gridlines and markup are drawn by the same small scene code in both, except the log-scale chart, whose axes are d3-axis's own markup (from the engine's Axis and SvgAxisWriter, and from d3-axis on a minimal DOM). No JavaScript runs on this page.

Summary

Compute time per chart: scales, ticks, tick labels and path strings, without the SVG markup. Median of 11 samples after a warm-up. Measured with both runtimes pinned to the same cores of an otherwise quiet machine (Intel(R) Core(TM) i7-14700, 4 threads; 1-minute load average 3.3–3.2 during the engine run, 3.4–3.3 during d3's).
